# dodgeball
Supplementary repository to ChewbaccaBox/dice.
Provides the schematic netlist used to generate dodgeball.cpp

## Gameplay
A one or two player game, with each player controlling a movable square. A player's points increase as long as they avoid being hit by balls. Four balls release each at set points and begin bouncing around each with their own pattern.

## What is DICE?
DICE is the Discrete Integrated Circuit Emulator, which emulates the oldest video games built with nothing but logic gates and archaic chips. The first games emulated in DICE were text encoded versions of the original game's schematics. To facilitate the implementation of these complicated circuits, they were simply redrawn digitally and automatically converted to the text-encoded netlist.
